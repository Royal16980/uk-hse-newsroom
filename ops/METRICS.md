# Metrics (North Star + supporting)

## North Star
- Weekly **qualified leads** (quote requests / calls booked)

## Supporting KPIs
Traffic:
- Organic clicks (weekly)
- Impressions (weekly)
- Top 10 pages by clicks

Conversion:
- Newsletter signup rate (landing + inline)
- Template gate conversion rate
- Quote request conversion rate

Monetisation:
- Affiliate clicks (by category)
- RPM/Ad readiness (later)

Quality:
- Publish velocity (drafts/week, shipped/week)
- Broken links / build failures
- Time-to-fix for automation failures
