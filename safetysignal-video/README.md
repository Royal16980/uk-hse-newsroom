# SafetySignal Video Studio (Remotion)

This repo is a Remotion + Next.js setup configured to generate **short-form vertical videos** with a consistent brand style.

It pairs with your OpenClaw skill `remotion-studio` (Creative Director → Social Media Specialist → Video Expert → Motion Designer → QA).

## What’s included
- Composition: **SafetySignalShort** (1080x1920, 30fps, 25s)
- Example voiceover: `public/audio/vo-default.mp3` (generated locally via OpenClaw TTS)
- Captions renderer: TikTok-style word stream (placeholder timings generated from script)

## Run locally
```bash
npm install
npm run dev
```

## Render the default short
```bash
npx remotion render src/remotion/index.ts SafetySignalShort out/safetysignal-default.mp4
```

Output (already rendered once on this machine):
- `out/safetysignal-default.mp4`

## Render with custom props
Create `props.json`:
```json
{
  "topic": "HSE enforcement",
  "hook": "Prosecutions don’t start in court.",
  "headline": "They start months earlier — with the same 3 failures.",
  "bullets": [
    "No ownership for critical controls.",
    "No verification (just paperwork).",
    "No learning loop after near-misses.",
    "This week: pick 1 high-risk task and verify the control in-person."
  ],
  "cta": "Follow SafetySignal UK for practical H&S leadership.",
  "bgImageUrl": "https://images.unsplash.com/photo-1521791055366-0d553872125f?auto=format&fit=crop&w=2000&q=80",
  "voiceoverUrl": "audio/vo-default.mp3"
}
```
Render:
```bash
npx remotion render src/remotion/index.ts SafetySignalShort out/custom.mp4 --props=props.json
```

## Captions (upgrade path)
Right now, captions are generated by evenly distributing word timings across a fixed duration (good enough for v1).

To upgrade to real word timestamps:
- Generate VO audio
- Run Whisper (STT) to get word timestamps
- Replace `captions` prop with real timings

## Security note (npm audit)
`npm audit` reports high-severity advisories in transitive Remotion serverless/AWS deps. Fixing them requires `npm audit fix --force` (breaking changes). We can do a controlled Remotion upgrade pass when you’re ready.
